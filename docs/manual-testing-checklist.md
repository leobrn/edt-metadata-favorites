# Чек-лист ручного тестирования

Этот чек-лист дополняет автоматические тесты проверками в реальном 1С:EDT. Он не повторяет
проверки компиляции, модульных тестов и внутреннего формата данных, выполняемые сборкой.

## Как использовать

- Не выполняйте весь документ после каждого изменения: это каталог проверок, а не единый
  обязательный сценарий.
- Для обычного функционального изменения выполните **короткий smoke-прогон** и один или несколько
  разделов затронутых областей.
- Для документационных, тестовых и внутренних изменений без изменения поведения ручной прогон
  не требуется.
- Полный прогон выполняйте только перед релизом или после сквозного архитектурного изменения.
- Зафиксируйте версию EDT, проверяемую сборку, конфигурацию и пропущенные пункты.

Рекомендуемое окружение: 1С:EDT 2026.1, отдельное рабочее пространство минимум с двумя проектами
конфигураций и объектами, содержащими формы, реквизиты, табличные части и команды. Для проверки
производительности нужна большая конфигурация.

## Короткий smoke-прогон — до 5 минут

- [ ] EDT запускается без ошибок активации плагина; команды доступны в Навигаторе и редакторе.
- [ ] Добавление и удаление объекта из Навигатора или редактора сразу обновляет его декоратор.
- [ ] Фильтр «Только избранное» показывает выбранный объект и путь к нему, не отключая другие
  активные фильтры Навигатора.
- [ ] Кнопка «Только изменённые Git» находится сразу после «Только избранное», переключает
  Git-фильтр и не отключает остальные активные фильтры Навигатора.
- [ ] Диалог управления открывается через `Ctrl+Alt+F`, показывает проекты и позволяет изменить
  один чекбокс мышью или клавишей `Space`.
- [ ] `ОК` применяет изменения и включает фильтр «Только избранное»; `Отмена` не изменяет
  сохранённое состояние.
- [ ] После закрытия диалога Навигатор сразу показывает применённый результат.

## Дополнительные проверки по области изменения

### Установка, обновление и релиз

- [ ] `scripts/build-release.ps1` создаёт update-site ZIP, bundle JAR, `release-notes.md`
  и `SHA256SUMS.txt` с корректной версией и контрольными суммами.
- [ ] Версия релиза не содержит `-SNAPSHOT`, а `release-notes.md` соответствует истории изменений.
- [ ] Плагин устанавливается через `Help → Install New Software` и появляется в списке
  установленного ПО после перезапуска.
- [ ] Обновление поверх предыдущей публичной версии сохраняет избранное пользователя.

### Навигатор и фильтр

- [ ] Избранный проект без отдельно выбранных объектов отображается целиком.
- [ ] Проект, не добавленный целиком, отображается при наличии избранных объектов вместе
  с полными путями к ним.
- [ ] Команды, неприменимые к текущему состоянию проекта или объекта, не отображаются.
- [ ] Изменение избранного через меню, горячую клавишу, редактор или диалог обновляет дерево сразу
  и не сворачивает ранее раскрытые пользователем узлы.
- [ ] Фильтр «Только изменённые Git» показывает добавленные, изменённые, индексированные
  и неиндексированные объекты вместе с путями к ним.
- [ ] Изменение только модуля или другого вспомогательного файла показывает владеющий объект
  метаданных.
- [ ] После добавления в индекс, отмены изменения или коммита Git-фильтр обновляется без
  перезапуска EDT и не блокирует интерфейс на большой конфигурации.
- [ ] После команды «Отклонить изменения» в окне индексирования объект исчезает из активного
  Git-фильтра без его повторного переключения.
- [ ] При включении Git-фильтра проекты раскрываются автоматически при количестве изменённых
  объектов до 300; при 301 и более дерево остаётся свёрнутым, а результаты не обрезаются.
- [ ] На большой конфигурации расчёт автоматического раскрытия не блокирует UI; при достижении
  защитного лимита обхода дерево остаётся свёрнутым.
- [ ] Проект вне Git и проект без изменённых объектов не отображаются; при ошибке чтения статуса
  дерево не становится ложно пустым, а ошибка записывается в Error Log.
- [ ] Одновременное включение «Только избранное» и «Только изменённые Git» показывает их
  пересечение без пустых родительских ветвей.

### Рекурсивное избранное

- [ ] «Добавить в избранное с вложенными» добавляет текущий состав выбранной ветки.
- [ ] Новый дочерний объект внутри рекурсивно выбранной ветки наследует избранное.
- [ ] Одиночное удаление потомка создаёт сохраняемое исключение, а повторное добавление отменяет его.
- [ ] Удаление вложенной ветки исключает её существующих и будущих потомков.
- [ ] Исключение вложенной ветки не влияет на соседние ветки того же рекурсивного родителя.

### Диалог управления избранным

- [ ] При открытии из редактора или Навигатора диалог выбирает связанный с активным элементом
  проект; если определить его нельзя, предпочитается проект с избранным, а затем первый
  по алфавиту.
- [ ] Группа показывает три состояния: ничего не выбрано, выбрана часть, выбрано всё.
- [ ] Мышь и `Space` корректно переключают одиночные объекты и раскрытые или свёрнутые группы;
  потомки показывают актуальное состояние и реагируют с первого раза.
- [ ] Массовые команды без поиска применяются ко всему текущему проекту, а при поиске —
  только к найденным объектам, но не к показанным для навигации предкам.
- [ ] В режиме «Только выбранные» пустые группы скрыты, «Выбрать все» отключена,
  а «Снять все» применяется только к показанным объектам.
- [ ] Пока изменённый поисковый запрос ожидает выполнения или рассчитывается, массовые команды
  недоступны, а статус показывает актуальное состояние поиска.
- [ ] Переключение проектов не теряет несохранённые изменения текущей сессии диалога.
- [ ] Закрытие изменённого диалога через `Escape` или крестик запрашивает подтверждение.

### Поиск в диалоге

- [ ] Один или два символа не запускают фильтрацию; поиск с третьего символа не зависит от регистра.
- [ ] В FQN-запросе вида `Catalog.Контр` совпавшая часть имени после последней точки выделяется
  жирным.
- [ ] Совпадение имени или FQN родителя не показывает его неподходящие формы, реквизиты
  и другие потомки.
- [ ] Явный вложенный путь, например `Catalog.Контрагенты.Form`, находит вложенные объекты,
  которые можно выбрать независимо от родителя.
- [ ] Русское имя типа в начале пути работает так же, как английское: `Справочник.Контр`,
  `Справочники.Контр` и `Catalog.Контр` дают одинаковый результат, а `Отчёт.` и `Отчет.`
  равнозначны.
- [ ] После запроса с русским типом статус показывает число найденных объектов, а не бесконечное
  «Поиск…», и кнопки массовых действий остаются доступными.
- [ ] Объект, названный как тип метаданных, не теряется: запрос `Справочник.Form` находит формы
  справочника с именем `Справочник`.
- [ ] Русские имена вложенных типов распознаются в любом сегменте пути: `Контрагенты.Форма`
  и `Справочник.Контрагенты.Реквизит` находят соответствующие вложенные объекты.
- [ ] Поиск корректно совмещается с режимом «Только выбранные».
- [ ] До 300 результатов пути раскрываются автоматически; при большем количестве дерево остаётся
  свёрнутым, а статус показывает полное число найденных объектов.
- [ ] Быстрый ввод, замена и очистка запроса не применяют устаревший результат, не сбрасывают
  несохранённые отметки и не блокируют интерфейс надолго.

### Хранение и жизненный цикл объектов

- [ ] После перезапуска EDT избранное и состояние фильтра соответствуют сохранённым данным.
- [ ] Переименование объекта не сбрасывает избранное, а читаемая FQN-метка обновляется
  в `pinned.yaml`.
- [ ] Удалённый или недоступный объект не показывается в дереве; открытие диалога не удаляет
  его сохранённую запись и записи отсечённых служебных веток.
- [ ] Состояния разных проектов с одинаковыми именами объектов не смешиваются.
- [ ] Ошибка записи в state location появляется в `Error Log` и не приводит к аварийному
  завершению EDT.

### Производительность

- [ ] Диалог открывается и крупные ветки раскрываются на большой конфигурации без неприемлемой
  задержки.
- [ ] Поиск, его очистка и массовые операции на большой конфигурации не блокируют UI
  на неприемлемое время.

## Завершение проверки

- [ ] Пройден короткий smoke-прогон и только разделы, относящиеся к изменению.
- [ ] Для пропущенных пунктов указано обоснование.
- [ ] Результаты, найденные проблемы и известные ограничения записаны в описании изменения.
