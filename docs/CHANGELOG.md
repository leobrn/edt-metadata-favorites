# Changelog

Все значимые изменения проекта фиксируются в этом файле.

## [1.2.0]

Первый публичный релиз плагина.

### Основные возможности

- Добавление в избранное проектов, объектов метаданных и вложенных объектов: форм, реквизитов,
  табличных частей, команд, макетов и других элементов.
- Добавление и удаление избранного из контекстного меню Навигатора, с панели открытого редактора
  или сочетанием клавиш `Ctrl+Alt+K`.
- Рекурсивное добавление ветки с автоматическим включением новых вложенных объектов, которые появятся
  в ней позднее.
- Форма массового управления избранным, доступная по `Ctrl+Alt+F`: переключение между проектами,
  выбор всех объектов, снятие всех отметок и режим «Только выбранные».
- Привычные трёхсостоянийные чекбоксы: группа показывает, когда выбраны все, часть или ни один
  из входящих в неё объектов.
- Поиск по имени объекта и техническому пути, например `Catalog.Контрагенты`, без учёта регистра.
- Фильтр «Только избранное» в Навигаторе. После подтверждения изменений в форме он включается
  автоматически.
- Звёзды рядом с избранными проектами и объектами в дереве Навигатора.
- Сохранение избранного в рабочей области EDT. Переименование объекта не сбрасывает отметку,
  поскольку объект распознаётся по стабильному идентификатору.

### Большие конфигурации

- Форма загружает только необходимые для управления избранным объекты и сохраняет привычную
  структуру Навигатора.
- Поиск и массовые операции не выполняют лишнее полное обновление дерева.
- Автоматическое раскрытие ограничено 300 найденными или избранными объектами. При превышении лимита
  результаты не обрезаются — дерево остаётся свёрнутым, чтобы не блокировать интерфейс.
- Удалённые или недоступные объекты не показываются пользователю в избранном.
